## Featured Project

### Pretext Playground

An interactive ASCII playground exploring what becomes possible when text is treated as a programmable visual medium.

The experience includes four interactive modes: an ASCII dragon that responds to mouse movement, physics-driven letters affected by gravity and collision, a fire-breathing text effect, and a 3D text tunnel that creates depth through character transformation.

| Interactive mode | What it demonstrates |
|---|---|
| **ASCII Dragon** | Pointer tracking and responsive character layout |
| **Physics Letters** | Particle motion, gravity, and collision behavior |
| **Fire Breathing** | Animated glyph selection and opacity changes |
| **3D Text Tunnel** | Perspective mathematics and coordinate transformation |

## Technical Focus

The Pretext Playground uses a two-stage rendering approach based around `prepare()` and `layout()`.

The `prepare()` stage generates and updates character data for each interactive mode. The `layout()` stage positions those characters on the canvas and manages responsive placement. Separating these responsibilities makes the animation and measurement model easier to reason about during resizing, pointer interaction, and repeated state changes.

```text
prepare()  →  generate and update characters
layout()   →  position characters on the canvas
render()   →  display the interactive result
```
